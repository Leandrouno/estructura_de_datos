## 🚀 Empezar a programar sin instalar nada

1. Creá una cuenta gratuita en [GitHub](https://github.com/signup) o iniciá sesión.
2. Entrá a este [repositorio](https://github.com/Leandrouno/estructura_de_datos).
3. Seleccioná **Fork → Create fork** para crear tu propia copia.
4. Desde **tu fork**, abrí **Code → Codespaces → Create codespace on main**.
5. En el editor, abrí cualquier archivo `.cpp`. Si el entorno no instaló la extensión automáticamente, buscá **C/C++ (Microsoft)** en Extensions e instalala.
6. Abrí **Terminal → New Terminal** para compilar y ejecutar.

### ▶️ Ejecutar un ejercicio C++

Desde la carpeta que contiene el archivo:

```bash
g++ codigo.cpp -o programa
./programa
```

Si estás en otra carpeta, indicá la ruta correspondiente entre comillas. Para verificar el compilador:

```bash
g++ --version
```

> [!NOTE]
> La extensión **C/C++** mejora la edición y la depuración, pero **no reemplaza** al compilador `g++`.

## 🔄 Guardar cambios y recibir novedades

**Tus propios cambios:** guardá los archivos y, para publicarlos en *tu fork*, usá Source Control → **Commit** → **Sync Changes**, o la terminal:

```bash
git add -A
git commit -m "Actualizo mis ejercicios"
git push
```

**Nuevas clases del repositorio principal:** entrá a tu fork en GitHub y elegí **Sync fork → Update branch**. Después, dentro de tu Codespace, ejecutá:

```bash
git pull
```

> [!IMPORTANT]
> **Trabajá en tu propia copia.** Para evitar conflictos al recibir actualizaciones, conservá los materiales compartidos como referencia y guardá tus soluciones personales en una carpeta como `Mis_Ejercicios/`. Si Git detecta cambios incompatibles, puede pedirte resolver conflictos; no los descartes sin revisarlos.
